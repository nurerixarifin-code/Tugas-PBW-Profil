1. What is the difference between an HTML tag and an HTML element? 
Answer:An HTML tag is the syntax used to mark the beginning or end of an instruction, enclosed in angle brackets (e.g., <p> or </p>). An HTML element includes everything from the opening tag, the content inside it, to the closing tag (e.g., <p>This is a paragraph.</p>).

2. Why do we use semantic elements such as <header>, <main>, and <footer>? 
Answer: Semantic elements give meaning to the structure of a web page rather than just defining its appearance. They help search engines (SEO) understand the content structure, improve accessibility for screen readers used by visually impaired users, and make the code easier for developers to read and maintain.
